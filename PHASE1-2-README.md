## What the work does

**Phase 0 — WebGL2 groundwork.** The context ladder prefers WebGL2, with WebGL1
kept as a complete fallback behind an `isGL2` flag. Existing GLSL 1.00 programs
compile unchanged; only new programs use GLSL ES 3.00. HDR targets use sized
internal formats on GL2.

**Phase 1 — lit volumetric dust.** Previously dust could only *subtract* light:
it was a dark multiplicative billboard, so it silhouetted but never glowed. Real
dust also scatters starlight. A 3D volume (RGB = stellar emissivity, A = dust
extinction) is mip-blurred to approximate irradiance and raymarched with single
scattering, self-shadowing and a forward phase function toward the core.

**Phase 2 — GPU particle-mesh layer.** A second population living entirely in
float textures: deposit → Jacobi Poisson → gradient → symplectic integration →
direct point rendering, up to 4.2M particles. It moves under the analytic
axisymmetric field plus particle-mesh self-gravity from its own density field, so
its spiral structure is not drawn — it grows from gravity. This is a grid/Poisson
method; there is deliberately no Barnes-Hut.

## Risk

Both systems are feature-gated and degrade cleanly. The volumetric renderer falls
back to the existing sprite dust on WebGL1 or if the volume fails to initialise.
The GPU layer is **off by default** and purely additive — the existing simulation
is untouched, and any initialisation failure disables the layer.
